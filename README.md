# Simple Interest Calculator

A simple Java program to calculate simple interest based on principal amount, rate of interest, and time period.

## Formula

Simple Interest (SI) = (P × R × T) / 100

Where:
- **P** = Principal amount
- **R** = Rate of interest (per annum)
- **T** = Time period (in years)

## Description

This program takes three inputs from the user — Principal, Rate, and Time — and calculates the simple interest using the standard formula. It's a beginner-friendly Java program that demonstrates basic input handling and arithmetic operations.

## Example

Input:
- Principal = 10000
- Rate = 5
- Time = 2

Output:
- Simple Interest = 1000
